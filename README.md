# Jasper's Zoo Maps

A mobile-first family zoo atlas prototype centered on Woodbine, Maryland.

## Included

- Interactive regional atlas for four starter zoos
- Smithsonian's National Zoo
- The Maryland Zoo in Baltimore
- Philadelphia Zoo
- Pittsburgh Zoo & Aquarium
- Persistent visited and wish-list tracking with `localStorage`
- Family zoo passport and collectible visit stamps
- Original interactive habitat maps for each zoo
- Featured animal cards with conservation notes
- Driving and transit directions from Woodbine through live Google Maps links
- Official zoo links for current hours, tickets, and animal lists
- Responsive desktop and phone layouts

## Run locally

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173`.

## Quality gates

```bash
npm test
npm run lint
npm run build
```

## Product boundary

This is a family-planning prototype, not an authoritative operational source. Travel times are approximate. Hours, access, ticketing, exhibits, and animal availability should be verified through each zoo's official site before traveling.

The habitat maps are original simplified illustrations; they do not reproduce proprietary zoo maps.
